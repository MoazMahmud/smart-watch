# Orbit Index — Store Listing

Fields for Zepp Console → Watchface → Watch Face Release.

| Field | Value |
| --- | --- |
| Watch Face Installation Package | The `.zab` exported by **Upload for Approval** in the Watchface Maker |
| Publish Area | Global |
| Supported Devices | Filled in automatically from the package (Amazfit GTR Mini) |
| Watchface category | Hybrid / digital-and-analog if offered, otherwise Simple or Digital |
| Language | English (Default) |
| Watch Face Preview (round screen) | `../assets/preview/preview_360.png` (360 × 360 PNG, non-AOD) |

## Watch Face Name

```
Orbit Index
```

## Watch Face Description

```
Orbit Index pairs a bold digital time with a quiet analog read. Roman numerals mark the hours, small numbers mark the minutes, and a turning tick ring carries the seconds past the minute window. Clean black-and-white design made for AMOLED, with a pure black background.
```

## Features Descriptions

```
- Large digital hour with minute window and live seconds
- Analog hour and minute hands with Roman numeral hour scale
- Rotating seconds tick ring
- Date, weekday and year
- Steps count
- Battery level with icon
- AM/PM in 12-hour mode
- Pure black background for AMOLED battery saving
```
